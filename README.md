# Тестовое задание по SQL

Ответ на тестовое задание по базам данных: пять запросов к PostgreSQL и короткий отчёт
о том, что нашлось при проверке.

Файлы:

- `schema.sql` — схема, на которой проверялись запросы, с индексами и ограничениями;
- `answer.txt` — сам ответ: запросы, результаты на тестовых данных, найденные ошибки
  и рекомендации.

Как проверял: поднимал PostgreSQL, заливал схему, заводил три категории, десять товаров,
пять клиентов и шесть заказов с девятью позициями. Каждый запрос выполнял и сверял
результат с ручным расчётом.

Что отметил в отчёте: без DISTINCT заказы дублируются по числу электронных позиций;
в первом запросе нужен GROUP BY по клиенту; сравнение года через EXTRACT с датой даёт
ошибку типов, надёжнее date_trunc; NULL в дате или цене ломает суммы; индексов на внешние
ключи и дату заказа в исходной схеме не было.

Рекомендации в конце ответа: индексы, ограничения NOT NULL и CHECK, статус и дата оплаты
в заказах, уникальность почты и названия товара внутри категории.
